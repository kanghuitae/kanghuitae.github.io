광고는 어디에 표시되나요

광고가 포함된 1.1 버전에서는 캘린더 화면 하단에 배너 광고 1개를 표시합니다. 일기 작성, 기록 상세, 온보딩, 설정과 알림 편집 화면에서는 배너를 표시하지 않습니다.

앱은 비개인화 광고와 Google의 제한적 데이터 처리(RDP)를 요청하도록 구성합니다. 이 설정을 적용해도 광고 제공·측정·보안·진단 등의 정보 처리가 있을 수 있습니다. 자세한 항목과 목적은 광고 1.1 개인정보처리방침에서 확인해 주세요.

광고가 보이지 않아도 일기를 쓸 수 있나요

광고를 불러오지 못하거나 필요한 개인정보 정보 갱신·선택 처리에 오류가 생겨 광고가 중단되어도 일기 작성·저장·열람 기능을 계속 사용할 수 있습니다.

광고 개인정보 선택을 다시 확인하려면 어떻게 하나요

앱 설정에 “개인정보 옵션”이 표시되는 경우 해당 항목을 눌러 선택 화면을 다시 열 수 있습니다. 안내와 선택지는 적용되는 지역 및 사용자의 선택 상태에 따라 달라질 수 있습니다.

개인정보 선택을 거절하거나 변경해도 일기 기능은 계속 이용할 수 있습니다. 선택 결과와 적용되는 요구사항에 따라 제한된 방식의 광고가 표시될 수 있습니다. 개인정보 선택 거절이 모든 광고나 모든 정보 처리를 중단하는 것은 아닙니다.

선택 화면이 열리지 않거나 변경 중 오류가 계속되면 앱 버전과 오류 상황을 문의 이메일로 알려 주세요. 문제 해결을 위해 앱 삭제부터 진행하지 마세요.

일기는 어디에 저장되나요

일기 내용, 날짜, 기분, 질문에 대한 답변과 첨부 사진은 기기의 앱 저장 공간에 저장합니다. 앱의 일기 작성·보관 기능은 이러한 데이터를 운영자나 제3자의 서버로 보내지 않습니다. 앱이 구성하는 광고 요청에도 일기 내용·날짜·기분·답변·사진이나 사진 파일 주소를 넣지 않습니다.

앱은 회원가입이나 자체 클라우드 동기화를 제공하지 않으며, 운영자 서버에 일기 사본을 보관하지 않습니다. 일기와 첨부 사진을 저장하는 폴더는 기기 백업에서 제외되도록 설정되어 있습니다. 별도의 일기 백업·복원 기능은 제공하지 않습니다.

사진은 어떻게 첨부하나요

iOS 사진 선택기에서 일기에 첨부할 사진을 선택합니다.

일기 알림은 어떻게 켜나요

알림 시간을 선택한 뒤 알림을 켜면 알림 권한을 요청합니다. 알림은 기기에서 예약되며 알림 본문에는 일기 내용이나 질문에 대한 답변을 표시하지 않습니다.

저장한 일기를 지우려면 어떻게 하나요

캘린더에서 기록한 날짜를 선택한 뒤 기록 상세의 삭제 기능을 이용하면 해당 날짜의 기록과 같은 날짜에 작성 중인 초안을 함께 제거합니다. 다른 기록에서 사용하지 않는 첨부 사진 파일도 정리합니다.

작성 중인 초안만 지울 수 있나요

캘린더에서 초안 삭제를 선택한 다음 확인하면 해당 초안을 삭제합니다. 취소하면 초안이 유지됩니다.

사진을 제거하거나 바꾸면 어떻게 되나요

다른 기록에서 사용하지 않는 사진 파일을 정리하고, 다른 일기에서 계속 사용하는 사진은 보존합니다. 정리에 실패하면 다시 시도하도록 처리합니다. 기기나 파일 상태에 따라 정리가 지연될 수 있으므로 문제가 계속되면 문의해 주세요. 사진 앱의 원본이나 앱 밖에 따로 보관한 사본은 이 정리의 대상이 아닙니다.

모든 기록을 한 번에 지울 수 있나요

현재 모든 날짜의 기록을 한 번에 삭제하는 기능은 제공하지 않습니다.

앱을 지우거나 기기를 바꾸면 복원할 수 있나요

앱은 계정 기반 복원이나 기기 간 동기화를 제공하지 않으며, 일기·사진 저장 폴더는 기기 백업에서 제외되도록 설정되어 있습니다. 운영자 서버에서 일기를 복구해 드릴 수 있는 구조도 아닙니다. 앱 삭제나 기기 변경 후 기록을 복원하지 못할 수 있으므로 보관이 필요한 기록을 먼저 확인해 주세요.

이 앱은 별도 계정을 만들지 않으므로 탈퇴 절차가 없습니다. 기기에 저장된 기록의 삭제 방법은 위 항목을 확인해 주세요. 로컬 기록 삭제와 외부 광고 서비스가 처리한 정보의 보관·삭제는 별개입니다.

오류가 생기면 재설치해도 되나요

기록이 사라질 수 있으므로 문제 해결을 위해 앱 삭제부터 진행하지 마세요. 먼저 앱 버전과 오류 상황을 확인하고 문의해 주세요.
